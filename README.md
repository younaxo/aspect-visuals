# Aspect Visuals

Визуальный клиент **Aspect Visuals** для Minecraft **1.21.4** на **Fabric**.

Стеклянный интерфейс (Peek / Panel), настраиваемый HUD и профиль пользователя,
который подтягивается с сайта [aspectvisuals.su](https://aspectvisuals.su).

## Возможности

- GUI Peek и Panel: поиск модулей, категории `HUD / Info / Visual`, карточки модулей и панель настроек
- Настраиваемый HUD с редактором: перетаскивание, привязки, масштаб
- Визуальные модули: FullBright, NoFog, время и погода, кастомный прицел, информационные виджеты
- Профиль аккаунта Aspect Visuals прямо в игре: аватар, ник, статус подписки
- Работа без сети: интерфейс и модули не зависят от доступности сайта

## Требования

- Minecraft 1.21.4
- Fabric Loader 0.16.9+
- Fabric API
- Java 21

## Сборка

```bash
./gradlew build
```

Готовый `.jar` появится в `build/libs/`.

## Запуск среды разработки

```bash
./gradlew runClient
```

## Установка

1. Установить Fabric Loader для 1.21.4.
2. Положить `aspect-visuals-<версия>.jar` и Fabric API в папку `mods`.
3. Запустить игру, открыть меню клавишей `Правый Shift`.

## Профиль Aspect Visuals

Клиент не хранит пароль от сайта. Вход выполняется по одноразовому коду:

1. В меню клиента нажать «Войти».
2. Клиент запрашивает у бэкенда одноразовый код с коротким сроком жизни.
3. Пользователь открывает страницу подтверждения на сайте и входит там обычным способом.
4. После подтверждения клиент получает ограниченный токен сессии и загружает профиль.

Токен сессии хранится отдельно от настроек клиента, отзывается с сайта
и не даёт доступа к административным действиям. Подробности —
в разделе «Подключённые сессии» личного кабинета.
