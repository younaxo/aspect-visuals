# Чтение исходника Figma

`decode.mjs` разбирает `.fig` в JSON: имена узлов, геометрию, заливки,
эффекты, текст и векторные контуры. Нужен, потому что обращения к Figma
через MCP ограничены тарифом, а макет требуется целиком и многократно.

    node tools/fig/decode.mjs canvas.fig doc.json

`canvas.fig` лежит внутри `.fig`, который выгружается из Figma: сам `.fig` —
zip, где рядом с `canvas.fig` находится папка `images` с растровыми
заливками. Векторы в `images` не попадают, они внутри `canvas.fig`.

Формат смешанный: схема сжата deflate, данные — zstd. Поэтому способ
распаковки выбирается по сигнатуре чанка, а не по его номеру.

## Иконки

    node tools/fig/icons.mjs canvas.fig

Пишет SVG в `src/main/resources/assets/aspectvisuals/icons`. После этого
нужен `node tools/render-icons.mjs`, который растеризует их в текстуры.

Иконки набора Lucide нарисованы обводкой, а не заливкой, поэтому берётся и
`fillGeometry`, и `strokeGeometry`: обводка приходит из макета уже
развёрнутой в контур, и её достаточно залить — повторять правила стыков и
концов линий не требуется.
