# Версии сборок

Основная версия — `0.1.0`. К ней приписывается счётчик сборки: `0.1.0-0.0.1a`.
Приписка увеличивается на каждое изменение, которое доходит до собранного jar,
основная версия остаётся прежней до крупного этапа.

Версия видна в игре: она выводится в виджете Watermark рядом с названием
клиента, поэтому по скриншоту всегда понятно, какая сборка запущена. Она же
попадает в имя jar — `aspect-visuals-0.1.0-0.0.1a.jar`.

Архив, который отдаёт GitHub Actions, называется так же, плюс короткий коммит
в скобках: `aspect-visuals-0.1.0-0.0.2a (9086a75)`. По имени скачанного файла
видно и версию, и от какого коммита он собран, без захода в прогон. В прогоне
на pull request берётся коммит ветки, а не merge-коммит, который создаёт
GitHub.

Формат допустим для Fabric: `0.0.1a` — это pre-release часть SemVer.

| Версия | Что изменилось |
|---|---|
| `0.1.0-0.0.4a` | Убран временный шаг разведки из сборки. |
| `0.1.0-0.0.3a` | HUD не рисовал фоны: виджет ставится на место сдвигом матрицы, а поле расстояния считалось по экрану. Координата фигуры переведена в атрибут вершины. Отладочный экран говорит о клиенте, а не о загрузчике. |
| `0.1.0-0.0.2a` | Архив сборки называется по версии и коммиту. |
| `0.1.0-0.0.1a` | Интерфейс не отрисовывался: фигуры считали положение по вершине, а она приходит во фрагмент уже умноженной на матрицу интерфейса. Положение переведено на `gl_FragCoord`. |
| `0.1.0` (без приписки) | Первые сборки: слой отрисовки через поле расстояния, SDF-текст, вход по одноразовому коду. Игра не запускалась — конфигурация применялась до создания настроек игры. |
